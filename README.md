# Portofolio M. Rizal Matofani — Versi Final Rapi

Website portofolio interaktif untuk VS Code, memakai HTML, CSS, JavaScript dan seluruh aset lokal.

## Perbaikan terakhir
- Mengganti monogram RM di navigasi dengan foto wajah yang dipotong rapi dalam avatar bulat.
- Membangun ulang kartu Education: tahun di baris atas, nama institusi di bawah, lalu program studi dan lokasi. Tidak ada lagi judul panjang berdempetan dengan tahun.
- Mempertahankan animasi ketik 4 kalimat, animasi potret, efek hover kartu, proyek, logo asli, dan link kontak.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Di VS Code pilih **File > Open Folder** dan pilih folder ini.
3. Buka `index.html` memakai **Live Server** atau langsung melalui browser.

Untuk mengedit: `index.html` = isi, `styles.css` = desain, `script.js` = interaksi.
